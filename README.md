# InstructCD
We formalize OVCD as instruction-following, decoupling each instruction into bi-temporal segmentation prompts and a change relation that filters the final change map to output exactly requested transitions. 

The data that support the findings of this study are openly available in the following repositories. The SECOND dataset is available at https://opendatalab.com/OpenDataLab/SECOND. The LEVIR-CD dataset is available at https://opendatalab.org.cn/OpenDataLab/LEVIR-CD. The WHU-CD dataset is available at https://gpcv.whu.edu.cn/data/building_dataset.html.
